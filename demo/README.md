Command used to make it:

```bash
pdf2epub convert demo/2406.11717v3.pdf -o demo/2406.11717v3.epub \
  --title "Refusal in Language Models Is Mediated by a Single Direction" \
  -a "Andy Arditi" -a "Oscar Obeso" -a "Aaquib Syed" -a "Daniel Paleka" \
  -a "Nina Panickssery" -a "Wes Gurnee" -a "Neel Nanda"
```

To read it on Kindle, send the `.epub` with **Send to Kindle**. You can use the Android share sheet (Share → Kindle), email it to your `@kindle.com` address, or upload it at amazon.com/sendtokindle.
The Kindle app does not open `.epub` files tapped directly from a file manager.
